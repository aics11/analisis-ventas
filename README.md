# Análisis de Ventas - Célula Ágil de Desarrollo

## Integrantes
- Ruben Alejandro Torres

## Escenario
Escenario B – Análisis de Ventas de una Pequeña Empresa

## Descripción del Dataset
Dataset simulado de ventas con 60 registros diarios de tres productos (A, B y C),
con información de fecha, cantidad vendida, precio unitario y total de venta.

## Instrucciones para ejecutar el script
1. Clonar el repositorio
2. Abrir Google Colab
3. Ejecutar el script: python scripts/analisis_ventas.py
4. Los resultados se guardan en la carpeta /resultados
